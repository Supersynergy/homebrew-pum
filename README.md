# Homebrew tap for PUM

[PUM](https://github.com/Supersynergy/pum) checks package freshness across multiple package managers and applies updates only when requested.

## Current status

This repository contains no Homebrew formula yet. Use the [PUM installation guide](https://github.com/Supersynergy/pum#install) for available installation options.

## Planned tap command

Once a verified formula is published, the intended installation command is:

```sh
brew install supersynergy/pum/pum
```

## Maintainer checklist

1. Publish the upstream release artifact.
2. Add a formula with its version, download URL and SHA-256 checksum.
3. Verify installation and `pum --help` before documenting the tap as available.
